# 5. KEY ARCHITECTURAL DISCOVERIES & INVARIANTS FROM THE MASTER SKILL

## The Phase 7 Hybrid Cinematic Scrubber (ORYZO / Superlocal Paradigm)
Real-time ray-tracing in WebGL overheats mobile GPUs and causes frame drops. The skill standardizes on the **Apple/ORYZO hybrid architecture**:
1. High-end camera movements, lighting, and reflections are baked offline in Blender Cycles into indexed WebP image sequences.
2. The sequence is preloaded into an in-memory `Image[]` array and painted onto Canvas 2D with exact `object-fit: cover` math driven by scroll.
3. Real-time lightweight Three.js meshes and 3D perspective DOM layers (`perspective: 1000px; transform-style: preserve-3d`) are layered over the canvas for interactive fidelity.

## 10% Rest Buffer Zone in Pinned Scrollytelling
Every pinned story sequence ($N \times \text{innerHeight}$) must complete its primary visual choreographies by progress $p = 0.90$. The final interval ($p \in [0.90, 1.00]$) is reserved as a resting buffer so elements dock cleanly before releasing the viewport, eliminating abrupt layout snapping.

## Mobile-Adaptive Particle Stride Optimization
On Canvas 2D particle text systems, sampling strides dynamically shift based on device capabilities:
- **Desktop**: 4px stride for razor-sharp particle density.
- **Mobile/Touch Devices**: 7px stride (reducing particle computation by 75%) to lock 60–120 FPS performance without thermal throttling.

# 7. BATTLEFIELD SCARS & CRITICAL INVARIANTS

### 1. The Legendary Scroll-Lock Container Trap (Commit `f986881`):
Lenis smooth scrolling locked completely when parents had `height: 100%`.
*Mandatory Root Invariant*:
```css
html { min-height: 100%; }
body { min-height: 100vh; overflow-x: hidden; }
html.lenis, html.lenis body { height: auto; }
```

### 2. Zero-Allocation Render Loop Invariant:
Zero `new` allocations inside `requestAnimationFrame` or `useFrame`. Pre-allocate scratch vectors (`_v1 = new THREE.Vector3()`) at module scope to eliminate garbage collection stutters.

### 3. Device Pixel Ratio Clamping:
`Math.min(window.devicePixelRatio, 2.0)` across Three.js and Canvas 2D to prevent GPU fill-rate overheating on Retina displays.
